# Foto asli Bakmi Jowo Anglo Pak Joko

Taruh foto di folder ini dengan nama file persis seperti tabel di bawah. Kalau file ada,
halaman memakai foto itu. Kalau belum ada, halaman tetap memakai ilustrasi garis SVG.

| Nama file (tanpa ekstensi) | Isi foto | Dipakai di |
|---|---|---|
| `wajan` | Wajan di atas anglo, api/bara terlihat | Hero Beranda, kartu 02 "Satu per satu", halaman Cerita |
| `anglo` | Tungku anglo dengan arang membara | Hero Beranda (dengan asap), kartu 01 "Tungku anglo", halaman Cerita |
| `bakmi-nyemek` | Bakmi Nyemek di mangkok | Hero Beranda, kartu 03 "Medok khas Jawa", poster Menu Andalan |
| `bakmi-goreng` | Bakmi Goreng di piring | Poster Menu Andalan |
| `es-teh` | Es teh / minuman | Hero Beranda (desktop) |

Aturan file:

- Ekstensi: `.webp` (utama), `.png`, atau `.jpg`. Contoh: `wajan.webp`.
- Supaya efek stiker (tepi putih mengikuti bentuk) jalan, pakai **latar transparan**
  (objek sudah dipotong/cut-out) dalam `.webp` atau `.png`. Foto `.jpg` tetap tampil,
  tapi berbentuk kotak dengan tepi putih.
- Ukuran sekitar 800 px sisi terpanjang, di bawah 200 KB per file.
- Hanya foto milik sendiri (IG @bakmi.pakjoko atau tim konten). Jangan foto stok.
- Setelah menambah atau mengganti foto, deploy ulang (foto dicek sekali per proses server).
